# External contract provenance

Selected DTOs adapted from DFINITY's Apache-2.0 external schema:
https://github.com/dfinity/ic/blob/f83a7646c20ce18100eb87b7865c12852bef8169/rs/ledger_suite/icp/ledger.did

The adjacent LICENSE retains the upstream terms and notices. Changes select the
consumed contract families, express them as Rust DTOs and add documentation and
standard derives. No service implementation or cryptographic code is included.

The repository's docs/external-contracts.md records exact mappings, schema
qualification and retained consumer responsibilities.
