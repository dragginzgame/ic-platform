# Management snapshot replay

`ledger-created.bin` is an independent native Candid creation reply from
`engine-view-consumer/tests/ledger.rs`. It preserves a block index of 2^128
and the returned canister identity. Regenerate explicitly with
`REGENERATE_LEDGER_FIXTURE=1` on that native test, then run
`make qualify-management-ledger`. See
[the management/ledger contract](../../../docs/qualification/management-ledger.md)
for schema provenance and evidence limits.

`snapshot-metadata.bin` is generated by the independently authored native
`metadata()` case in `engine-view-consumer/tests/management_snapshots.rs`, through
original registry Candid 0.10.40 and management types 0.8.0. The qualification
lock records their exact sources/checksums. It exercises signed integer extremes,
raw NaN payload bits, maximum u128, absent globals, reserved provenance, timer,
hook, chunk hashes and exact full-width metadata values.

Ordinary native tests compare the frozen bytes to the independent producer.
Regenerate deliberately from the repository root:

```sh
REGENERATE_SNAPSHOT_CORPUS=1 cargo test --locked \
  --manifest-path qualification/Cargo.toml -p engine-view-consumer \
  --features management-snapshots --test management_snapshots frozen_metadata
```

Review changed bytes, then run `make qualify-management-snapshots`. The standalone
Wasm executable only consumes the data; no upstream Candid or management DTO
implementation is selected in its graph. See the
[contract](../../../docs/qualification/management-snapshots.md) for evidence limits.

The `caffeine-*.bin` files are independent native Candid schema frames from
`engine-view-consumer/tests/caffeine.rs`, not product-encoder output. Regenerate
only explicitly with `REGENERATE_CAFFEINE_CORPUS=1`; ordinary tests compare their
bytes. They cover root batches, the plain certificate record and an arbitrary
negative Cashier balance. See `docs/qualification/blob-suppliers.md` for limits.

The `sns-*.bin`, `icrc-symbol.bin` and `icrc-balance.bin` frames come from independent
Candid schemas in `engine-view-consumer/tests/sns.rs`. Ordinary tests compare
frozen bytes; regenerate with `REGENERATE_SNS_FIXTURES=1 cargo test --locked
--manifest-path qualification/Cargo.toml -p engine-view-consumer --features
sns-neurons --test sns` (as one shell command), review bytes, then run
`make qualify-sns-neurons`. See the [pinned contracts and projection
limits](../../../docs/qualification/sns-neurons.md).

The `root-*.bin` requests are frozen registry Platform 0.33.7 output; `root-status.bin`
is independently authored Candid output. Native and Wasm compare exact retained
request bytes and required version decoding. Provenance and deliberate regeneration
are documented in [Canic supplier qualification](../../../docs/qualification/canic-management.md).
# Backup status provenance

`backup-status-promoted-hash.bin` is independently generated by the native
`capture_hash_known_promotion_preserves_bytes_and_refusal_boundaries` test using
registry Candid 0.10.40. It contains stopped status, the anonymous controller,
version `u64::MAX` and a bare 32-byte `0x44` module hash. SHA-256:
`1b1d7cdd84c401f1570d46372d57d591ba68134c6f071c80c91e9874c104cd2c`.
Regenerate only with `REGENERATE_CAPTURE_STATUS_CORPUS=1` on that native test;
ordinary runs compare with the frozen bytes. This is new independent test data,
not a copied Backup encoder or proof of hash/controller admission.

`backup-status-{stopped,stopping,running}.bin` are the decoded `reply_hex` data
from [Backup's original status goldens](https://github.com/dragginzgame/ic-backup/blob/2941ca1324a95c1afdb57e33cef79362c28b0731/crates/ic-backup/src/store/capture/status/wire/golden.json).
Source ownership: Toko Studios, TOKO STUDIOS NETWORK LICENCE 1.0 (the source
repository's `LICENSE.md`). Only wire data is retained; no implementation,
generated mapping or test body was copied. These independent frames omit
version and module hash and exercise all three states and canonical controllers.

| State | SHA-256 |
| --- | --- |
| stopped | `3f618a4d42fb305f3f771d3b06265f854e9bfb1b491e8fbdba8f83cdd0871685` |
| stopping | `1b521fcff4cc6a421cd9375eb62c6e0b32a8d9ac746b4eb6645fb20226449626` |
| running | `7887df26eaadfc8ccdbb1e314307b1db9cfeed9ccb56c8751d387622126bcb91` |

Consumers must not infer authentication from decoding these untrusted frames.
The minimal capture projection accepts them; the upgrade projection must still
refuse their absent version. The focused management-snapshots profile replays
them on native and Wasm targets without reading a sibling at test time.
